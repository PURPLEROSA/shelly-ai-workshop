# 03 · ניוזלטר שכותב את עצמו (כמעט) · דף מנחה

**ערב 1 · `2' פתיח · 6' דמו · 10' תרגול · 4' סיכום = 22'`**

**המשפט שפותח:** "השיטה של Grok Bot: עושים פעם אחת בצ'אט, ואז אומרים 'תשמור את זה כ-skill'. מכאן זה כלי."

## דמו חי (6')
1. אצל בוט הסושיאל (אותו קול, אז אותו בוט):

```
בוא נכין ניוזלטר. השבוע: העברתי סדנה בטכניון, יצא כלי חדש של xAI, ולקוחה שלחה הודעה מרגשת.
תכין:
1. טיוטה עד 250 מילים בקול שלי, פתיחה אישית במשפט אחד.
2. 3 כותרות: סקרנית, ישירה, מצחיקה.
3. גרסת פוסט (עד 80 מילים) וגרסת סטורי (3 שורות).
לא ממציאים קישורים, מספרים או ציטוטים. כל קישור מסומן [לבדוק].
```

2. מתקנים דבר אחד בטיוטה, ואז:

```
תשמור את התהליך שעשינו כ-skill בשם "ניוזלטר שבועי". הקלט: 3 עד 5 דברים מהשבוע. הפלט: מה שעשינו עכשיו, כולל התיקון. הכלל: הטיוטה מחכה לעריכה שלי ולא נשלחת.
```

3. מספרים את הסיפור: בוט ניוזלטר שמחנה טיוטה ל"מעבר עריכה אחד" (TH16), ושהכשל הנפוץ הוא קישורים מומצאים.

## תרגול (10') · לבד
מריצים על השבוע שלהם ושומרים את ה-skill. **התוצאה:** טיוטה, כותרת שהם אוהבים, ו-skill שמור.

## שאלה לסיכום (4')
"מה הנגיעה האישית שרק אתם יכולים להוסיף?"

## הגשר לערב 2
"בשבוע הבא ה-skill הזה ירוץ לבד כל שישי ב-08:00, כ-routine."

## איפה נתקעים
- **טיוטה גנרית** ← הקלט דל מדי. פרט אחד קונקרטי לכל נקודה.
- **"הבוט מוסיף קישורים"** ← לבדוק כל אחד. זו בדיוק הסיבה לתג `[לבדוק]`.
