# 08 · מערכת חדשות של אדם אחד · דף מנחה

**ערב 2 · `3' פתיח · 8' דמו · 8' תרגול · 3' סיכום = 22'`**

**המשפט שפותח:** "שנתיים עשיתי פינת AI בטלוויזיה. הנה איך נראית מערכת החדשות שלי היום."

## המודל על השקף
מקורות ← **סורק** ← **עורך** ← **כותב** ← **השלב הסודי** ← **אתם מאשרים**
כל תחנה מקבלת את הפלט של הקודמת. Anthropic קוראים לזה prompt chaining, וכותבים שהצוותים שהצליחו "weren't using complex frameworks", אלא דפוסים פשוטים.

**"השלב הסודי"** (נחשף רק בזום): **עורך-בודק**. סוכן שקורא את הטיוטה מול רשימת קריטריונים ומחזיר אותה לתיקון. Anthropic קוראים לזה evaluator-optimizer, ומתאים "when we have clear evaluation criteria".

## דמו חי (8')
שרשרת בצ'אט אחד, שלב אחרי שלב:

```
שלב 1, סורק: מה קרה ב-24 השעות האחרונות בעולם ה-AI? 10 פריטים, שורה לכל אחד, עם קישור.
```
```
שלב 2, עורך: מתוך ה-10, תבחר 3 שמעניינים בעלי עסקים קטנים בישראל. לכל אחד: למה זה חשוב להם, במשפט.
```
```
שלב 3, כותב: לכל אחד מה-3, טיוטת פוסט עד 60 מילים בקול של סושיאל.
```
```
שלב 4, בודק: תקרא את 3 הטיוטות מול הקריטריונים: (א) יש קישור שנפתח, (ב) אין מספר בלי מקור, (ג) עד 60 מילים, (ד) נשמע כמוני ולא כמו תרגום. תחזיר טבלה של עבר/נכשל ותתקן את מה שנכשל.
```

אחרי זה: כל שלב יכול להיות אוטומציה נפרדת שמזינה את הבאה (סורק ב-06:00 ← טיוטות ב-06:30). **[לאמת]** אם אוטומציה יכולה לקבל פלט של אוטומציה אחרת. אם לא, מאחדים לאוטומציה אחת עם 4 שלבים כתובים.

**Grok Bot (דקה, "לאן זה הולך"):** סוכן עם מחשב משלו בענן, שנכנס לכלים שלכם ומבקש אישור. יצא בבטא ב-11.8.2026, ורק במסלולים היקרים. לא בונים אותו הערב.

## תרגול (8') · זוגות
שרשרת של 3 שלבים על התחום שלהם: סורק, עורך, כותב. בן הזוג משחק את "אתם מאשרים". **התוצאה:** טיוטה אחת שעברה 3 תחנות.

## שאלה לסיכום (3') · מתוך המחלוקת הגדולה
"דף הנחיתה מבטיח 'עונה ללידים בזמן שאתם ישנים'. המבקרים אומרים שסוכנים הם ג'וניורים מהירים שטועים בביטחון. אחרי שני ערבים, איפה אתם?" והתשובה שלי: הוא מכין הכל בלילה, ואתם מאשרים בבוקר.

## איפה נתקעים
- **השרשרת "שוכחת" שלבים** ← שלב אחד בכל הודעה, לא הכל בבת אחת.
- **הבודק מאשר הכל** ← הקריטריונים כלליים מדי. כל קריטריון צריך להיות משהו שאפשר לענות עליו בכן/לא.
