# 07 · רוטינות בזמן שאתם ישנים · דף מנחה

**ערב 2 · `2' פתיח · 7' דמו · 10' תרגול · 3' סיכום = 22'`**

**המשפט שפותח:** "עד עכשיו ביקשנו. מעכשיו הוא עושה לבד. זה ההבדל בין צ'אט לסוכן."

## המודל על השקף
**Automation = הוראות + מתי (שעה או מייל שמפעיל) + connectors + skill.**
כל ריצה מתחילה מחדש עם הדאטה העדכני (מתוך ההודעה הרשמית של xAI, 16.7.2026).

## דמו חי (7')
1. פותחים את עמוד **Automations**, או כותבים בצ'אט "תיצור אוטומציה". **[לאמת]** הנתיב.
2. תדריך בוקר:

```
כל יום בשעה 06:00, שעון ישראל:
1. מהיומן: מה יש לי היום, לפי סדר.
2. מ-Gmail: עד 3 מיילים שדורשים תשובה היום, שורה לכל אחד. לא שולחים ולא משנים כלום.
3. מ-X: נושא אחד חם בתחום [התחום שלי], ב-2 שורות.
עד 12 שורות, בעברית.
```

3. **Run now** לפני שמירה. מראים את הפלט ומתקנים שורה אחת.
4. שומרים עם לוח זמנים: יומי, 06:00.
5. מהר, אוטומציה שנייה עם טריגר: `כשמגיע מייל שהנושא שלו מכיל "הזמנה" או "הצעת מחיר": תסכם אותו ותנסח טיוטת תשובה לפי ההוראות של מנהלת המשרד.` **[לאמת]** שטריגרים של מייל דורשים SuperGrok.
6. מחברים את ה-Skill מערב 1: `ניוזלטר שבועי, כל שישי ב-08:00`.

## תרגול (10') · לבד
כל משתתף בונה אוטומציה אחת (תדריך בוקר, או הבעיה שעלתה בסיכום של מודול 06) ומריץ Run now. **התוצאה:** אוטומציה שמורה שתחכה לו מחר בבוקר.

## שאלה לסיכום (3')
"מה הדבר הראשון שהייתם רוצים לראות מחר בבוקר ב-06:00?"

## איפה נתקעים
- **אין לוח זמנים או יש מגבלה על מספר האוטומציות** ← תלוי במסלול **[לאמת]**. בגרסה הישנה (Tasks): משימה יומית אחת בחינמי, 10 בתשלום.
- **הפלט ארוך מדי** ← להוסיף מגבלת שורות להוראות.
- **רץ בשעה הלא נכונה** ← לבדוק את אזור הזמן בהגדרות.
