# 07 · רוטינות בזמן שאתם ישנים · דף מנחה

**ערב 2 · `2' פתיח · 7' דמו · 10' תרגול · 3' סיכום = 22'`**

**המשפט שפותח:** "עד עכשיו ביקשנו. מעכשיו הוא עושה לבד, במחשב שלו, גם כשהלפטופ שלכם סגור."

## על השקף
**Routine = הבוט שאחראי על המשימה + skill + מתי (שעה או אירוע).**
מהתיעוד: "Schedule a routine last, and only after a test run."

## דמו חי (7')
1. אצל מנהלת המשרד (היא מחזיקה את המייל והיומן):

```
בואי נבנה תדריך בוקר. קודם ריצת בדיקה, עכשיו:
1. מהיומן: מה יש לי היום, לפי סדר.
2. מ-Gmail: עד 3 מיילים שדורשים תשובה היום, שורה לכל אחד. בלי לשלוח ובלי לשנות.
3. שורה אחת: הדבר הכי חשוב לעשות היום.
עד 10 שורות.
```

2. מתקנים שורה אחת. אחר כך:

```
מעולה. תשמרי את זה כ-skill בשם "תדריך בוקר", ותיצרי routine שמריצה אותו כל יום ב-06:00 שעון ישראל.
```

3. Notifications פועל ← התדריך מגיע כהתראה.
4. מחברים את ה-skill מערב 1, אצל בוט הסושיאל: `תיצור routine שמריצה את "ניוזלטר שבועי" כל שישי ב-08:00 וממתינה לעריכה שלי.`
5. **רגע המכסה (1'):** "routine כל 30 דקות אוכלת מכסה מסביב לשעון. כשהמכסה השבועית נגמרת, כל הרוטינות נעצרות." מראים את Settings ← Usage & Billing. **[לאמת]**

## תרגול (10') · לבד
ריצת בדיקה ← skill ← routine (תדריך בוקר, או הבעיה מהסיכום של מודול 06). **התוצאה:** routine שמורה שתחכה להם מחר בבוקר.

## שאלה לסיכום (3')
"מה תרצו לראות מחר ב-06:00? ומה מהרשימה שלכם יכול להיות אירוע במקום תזמון?"

## איפה נתקעים
- **ה-routine לא רצה** ← הבוט הנכון? אזור הזמן? יש מכסה?
- **הפלט ארוך מדי** ← מגבלת שורות ב-skill.
- **"אפשר כל 10 דקות?"** ← אפשר, וזה יגמור את המכסה. מעדיפים אירוע (מייל חדש) על תזמון צפוף.
