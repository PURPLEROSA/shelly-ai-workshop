# 02 · סוכן סושיאל בקול שלכם · דף מנחה

**ערב 1 · `2' פתיח · 6' דמו · 10' תרגול · 4' סיכום = 22'`**

**המשפט שפותח:** "למה בוט שני ולא עוד משימה למנהלת המשרד? כי סושיאל הוא תפקיד מומחה יציב, וככה התיעוד אומר להוסיף בוט."

## דמו חי (6')
1. **New chat** ← **Create new agent** ← Edit Profile: `סושיאל`, תפקיד `מנסח פוסטים בקול של שלי`.
2. הודעת הגדרה עם 3 פוסטים אמיתיים:

```
התפקיד שלך: לנסח לי פוסטים לאינסטגרם ולינקדאין, בקול שלי. אתה אף פעם לא מפרסם בעצמך.
אלה 3 פוסטים שכתבתי: [הדבקה]
תנתח את הקול שלי: אורך משפטים, מילים שחוזרות, איך אני פותחת ואיך אני סוגרת, מה אני אף פעם לא עושה.
תזקק את זה ל-5 כללי כתיבה ו-5 דוגמאות "כן / לא", ותזכור אותם.
```

3. משימה אמיתית: `תכין 3 טיוטות לשבוע: טיפ, מאחורי הקלעים, שאלה לקהל. לכל אחת: כותרת, טיוטה והצעה לוויז'ואל במשפט.`
4. מתקנים טיוטה בלייב ("אני לא כותבת 'מסע'"), ואז אומרים לו: `תזכור את זה ככלל.`
5. שומרים כ-skill:

```
תשמור את התהליך שעשינו עכשיו כ-skill בשם "פוסט בקול שלי". כלול את כללי הקול, הפורמט של 3 הטיוטות, והכלל שאתה אף פעם לא מפרסם.
```

## תרגול (10') · לבד
בוט סושיאל, 3 פוסטים שלהם, טיוטה אחת לפוסט של מחר, ו-skill שמור. **התוצאה:** 5 כללי קול שמורים בבוט.

## שאלה לסיכום (4')
"מה ה'לא' שהכי הפתיע אתכם ברשימה?"

## איפה נתקעים
- **אין 3 פוסטים** ← מיילים ללקוחות, הודעות עסקיות או תמליל הקלטה.
- **הטיוטה נשמעת מתורגמת** ← כלל: "עברית מדוברת ישראלית, לא תרגום." **[לאמת]** את איכות העברית לפני 2.11.
- **ה-skill לא נשמר** ← לבקש מהבוט לאשר את השם ולהראות את מה ששמר.
