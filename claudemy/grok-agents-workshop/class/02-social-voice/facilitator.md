# 02 · סוכן סושיאל בקול שלכם · דף מנחה

**ערב 1 · `2' פתיח · 6' דמו · 10' תרגול · 4' סיכום = 22'`**

**המשפט שפותח:** "'תכתוב בטון חם ומקצועי' זה מה שכולם כותבים, ולכן כולם נשמעים אותו דבר. קול בונים מדוגמאות."

## דמו חי (6')
1. מדביקים 3 פוסטים אמיתיים שלך (שלי) לצ'אט, ואז:

```
אלה 3 פוסטים שכתבתי. תנתח את הקול שלי: אורך משפטים, מילים שחוזרות, איך אני פותחת ואיך אני סוגרת, מה אני אף פעם לא עושה.
אחר כך תזקק את כל זה לפסקה אחת של הוראות כתיבה, ומתחתיה 5 דוגמאות "כן / לא".
```

2. מעתיקים את הפסקה לשדה ההוראות של הסוכן ממודול 01 (או לסוכן חדש בשם `סושיאל`).
3. צ'אט חדש:

```
סושיאל, תכין תוכנית תוכן לשבוע: 3 פוסטים, אחד מכל סוג: טיפ, סיפור מאחורי הקלעים, שאלה לקהל.
לכל פוסט: כותרת, טיוטה, והצעה לוויז'ואל במשפט אחד.
```

4. מתקנים טיוטה אחת בלייב ("זה לא אני, אני לא כותבת 'מסע'"), ומראים איך התיקון נכנס ככלל חדש בהוראות.

## תרגול (10') · לבד
כל משתתף: 3 פוסטים שלו ← פסקת קול ← טיוטה אחת לפוסט של מחר. **התוצאה:** פסקת קול שמורה בסוכן.

## שאלה לסיכום (4')
"מה ה'לא' שהכי הפתיע אתכם ברשימה?" כאן אנשים מגלים הרגלים שלא ידעו שיש להם.

## איפה נתקעים
- **אין 3 פוסטים** ← מיילים ללקוחות, הודעות וואטסאפ עסקיות או תמליל של הקלטה קולית. כל טקסט שנכתב בקול שלהם.
- **הטיוטה מתורגמת מאנגלית** ← להוסיף כלל: "כותבים עברית מדוברת ישראלית, לא תרגום." **[לאמת]** את איכות העברית של Grok לפני 2.11.
- **ההוראות עברו את מגבלת התווים** ← לקצר את הדוגמאות, לא את הכללים. המגבלה היא בערך 4,000 תווים לסוכן **[לאמת]**.
