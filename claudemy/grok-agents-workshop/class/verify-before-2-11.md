# לאמת ב-Grok Bot לפני 2.11

מגבלת הרשת חסמה את docs.x.ai ואת cursor.com. הפרטים האלה באים מתקצירי חיפוש, ורבים מהם מצטטים את התיעוד הרשמי. 45 דקות באפליקציה סוגרות את כולם. **מה שמסומן ★ נכנס למייל ההכנה, אז בודקים אותו קודם.**

## מנוי והתקנה
- [ ] ★ שם המסלול והמחיר: Premium, 30$ לחודש, ב-"The X Subscription" שהושקה ב-12.10.2026? (רישומים ישנים: SuperGrok)
- [ ] ★ מאיפה מורידים: הדשבורד של Cursor, x.ai/bot או cursor.com/download/bot?
- [ ] ★ התחברות דרך חשבון Cursor + חיבור חשבון Grok: איך זה נראה בפועל, צעד אחר צעד (לצלם)
- [ ] ★ Privacy Mode (Legacy): מה המשתתף רואה, ומה בוחרים
- [ ] אפשר לבטל מיד אחרי הסדנה?

## בניית בוטים
- [ ] New chat ← Create new agent ← "New Agent"
- [ ] Bot actions ← Edit Profile (שם, תפקיד, תיאור)
- [ ] העלאת קובץ לבוט: איפה ואיך
- [ ] "מה אתה זוכר עליי?" עונה בצורה שימושית?
- [ ] שמירת skill מהצ'אט ("תשמור את התהליך כ-skill בשם...")
- [ ] **איכות העברית:** טיוטת פוסט בעברית נשמעת טבעית?

## אישורים וחיבורים
- [ ] Settings ← General ← Bot: כללי Ask first, ואיך נראה כרטיס האישור
- [ ] Auto Review פעיל אצלך? (לפי המקורות, רק בחלק מהגרסאות)
- [ ] איפה מחברים Gmail ו-Calendar ב-Grok Bot, ואיך בוחרים טיוטות בלי שליחה
- [ ] Plugins ← Marketplace: קיים? מה יש בו?
- [ ] התראות לכל בוט (Bot settings ← Notifications)

## רוטינות ומכסה
- [ ] יצירת routine מבקשה בצ'אט, ו-Add routine במובייל
- [ ] טריגר אירוע (מייל חדש) מול תזמון
- [ ] Settings ← Usage & Billing: מה רואים (אחוזים בלבד?)
- [ ] on-demand: איפה מכבים או קובעים תקרה
- [ ] מה קורה כשהמכסה נגמרת (לפי המקורות: הבוט נעצר עד האיפוס השבועי)

## צוות ומחשב
