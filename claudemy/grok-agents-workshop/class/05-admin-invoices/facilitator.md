# 05 · חשבוניות ואדמין · דף מנחה

**ערב 2 · `3' פתיח · 6' דמו · 10' תרגול · 3' סיכום = 22'`**

**המשפט שפותח:** "הערב נותנים לסוכן ידיים. מתחילים בידיים שרק קוראות."

## לפני הדמו: רגע של אמון (חובה, 1')
- **Settings** ← בודקים את הגדרות השיתוף והאימון על הנתונים, ומחליטים בעיניים פקוחות **[לאמת]** את שמות ההגדרות.
- מחברים **קריאה בלבד**. טיוטות ושליחה מוסיפים רק כשסומכים. כל רמה היא הרשאה נפרדת (porteden).

## דמו חי (5')
1. ווב: כפתור **+** ← **Connectors** ← Gmail. במובייל: Settings ← Connectors.
2. 

```
תעבור על המיילים מ-7 הימים האחרונים ותן לי:
1. מה דורש ממני תשובה היום (עד 5), ולכל אחד שורה אחת של למה.
2. מי שלח חשבונית או ביקש תשלום, ומי עוד לא שילם לי לפי המיילים.
אל תשלח שום דבר ואל תשנה שום דבר.
```

3. תזכורת תשלום לפי שלבים:

```
תנסח 3 תזכורות תשלום לחשבונית [מספר] על סך [סכום] שהיה צריך להיות משולם ב-[תאריך]:
גרסה לשבוע איחור (חברית), ל-30 יום (ברורה, עם תאריך יעד), ל-60 יום ומעלה (תקיפה ומנומסת, עם הצעה לשיחה).
```

## תרגול (10') · לבד
מחברים Gmail בקריאה בלבד ומריצים את הבקשה הראשונה. **התוצאה:** רשימת "מה דורש תשובה היום".

**חלופה למי שלא רוצה לחבר מייל:** מדביקים 3 מיילים (בלי פרטים מזהים) ומבקשים את אותו סיכום.

## שאלה לסיכום (3') · מתוך המחלוקת
"יועץ בריטי טוען שתזכורות של AI רכות מדי, ומלמדות לקוחות שמאחרים שאתם לא בעדיפות. איזו מ-3 הגרסאות הייתם שולחים באמת?"

## איפה נתקעים
- **Google מבקש הרשאות רחבות** ← עוצרים וקוראים מה מאשרים. בהתלבטות, לא מאשרים.
- **הוא "מצא" חוב שלא קיים** ← בדיוק בשביל זה הכלל "הסוכן מנסח, אני שולחת".
- **חשבון עסקי ב-Google Workspace** ← ייתכן שמנהל החשבון צריך לאשר.
