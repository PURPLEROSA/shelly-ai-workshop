# שלד הרצאה · סוכנים מאפס עם Grok Bot

לשקפים (להעביר ל-keynote-by-shelly). כותרות של עד 7 מילים.

## פתיח (5')
- **הוק:** "קמים בבוקר. הצוות כבר עבד כל הלילה." ואז: "ושום דבר לא נשלח. הכל מחכה לכם." שני המשפטים יחד הם ההבטחה.
- **המהלך:** Grok Bot הוא לא צ'אט. זה צוות בוטים עם מחשב משלו בענן, שעובד גם כשהלפטופ סגור.
- **ההבטחה במשפט:** "בסוף שני ערבים יהיה לכם צוות קטן שמכיר אתכם, ו-routine אחת שמחכה לכם בבוקר."
- **שקף:** `צ'אט מחכה. בוט כבר עבד.`

## מערכה 1 · הצוות הראשון (ערב 1)
| | |
|---|---|
| **הטענה** | בוט אחד = תפקיד אחד. ההגדרה נעשית בהודעה הראשונה. |
| **מהתיעוד** | "Give one Bot ownership of an end-to-end outcome." "In your first message, give the Bot its job, sources, and approval boundaries." |
| **הסיפור** | הבוט הראשון שלי, מנהלת המשרד, וה-`[למלא]` שהציל אותי מהצעת מחיר מומצאת |
| **שקפים** | `בוט אחד, תפקיד אחד, משפט אחד` · `ההודעה הראשונה היא חוזה העבודה` · `אין מסך זיכרון. שואלים אותו.` |
| **רגע קהל** | "מי כתב פעם 'תכתוב בטון חם ומקצועי'?" |

## מערכה 2 · הקול והתוכן (ערב 1)
| | |
|---|---|
| **הטענה** | עושים פעם אחת בצ'אט, ושומרים כ-skill. הבוט גולש בשבילכם ב-X ומחזיר זווית. |
| **מהמדריכים** | "Users who got good drafts fed their bots transcripts, past posts... first." |
| **שקפים** | `קול בונים מדוגמאות, לא מתארים` · `עשית פעם אחת? תשמור כ-skill` · `הטרנד עלה בבוקר. הטיוטה כבר מוכנה.` |
| **רגע קהל** | "תגובה אוטומטית ב-X: מגניב או מביך? הצביעו." |

## מערכה 3 · הידיים והאמון (ערב 2)
| | |
|---|---|
| **הטענה** | מחברים מייל ויומן, אבל קודם קובעים מה אסור. Ask first מנצח הכל. |
| **מהתיעוד** | כל הבוטים חולקים מחשב אחד, ובוטים נפרדים הם לא גבול אבטחה. מיילים מ-routines מחכים כטיוטות עד Send. |
| **שקפים** | `קודם מה אסור, אחר כך מה מותר` · `הוא מנסח. אתם שולחים.` · `וואטסאפ לא רשמי = חשבון בסכנה` |
| **רגע קהל** | "תזכורת תשלום: רכה או תקיפה?" |

## מערכה 4 · הצוות עובד לבד (ערב 2)
| | |
|---|---|
| **הטענה** | Routine היא skill עם שעון. צוות הוא רשימה פשוטה, לא מדע בדיוני. |
| **מהתיעוד** | "Schedule a routine last, and only after a test run." |
| **הסיפור** | מערכת החדשות שלי: סורק ← עורך ← כותב ← **בודק** ← אני |
| **שקפים** | `ריצת בדיקה לפני לוח זמנים` · `30$ לחודש, עד ש-routine צפופה גומרת את המכסה` · `מערכת חדשות שלמה. אישה אחת.` · `השלב הסודי: מי בודק את הכותב` |
| **רגע קהל** | "כמה אוטונומיה אתם נותנים לצוות מחר?" |

## סגירה (5')
5 כללים לשמור (שקף אחד):
1. בוט אחד, תפקיד אחד.
2. כל תיקון שלי, הבוט זוכר.
3. Ask first על כל מה שיוצא החוצה.
4. ריצת בדיקה לפני לוח זמנים.
5. מוסיפים בוט רק לתפקיד מומחה יציב.

**משפט סיום:** "הם עובדים בלילה. אתם מחליטים בבוקר."

## הערות לבמה
- להגיד בקול: Grok Bot יצא בבטא באוגוסט, ונכנס למסלול של 30$ באוקטובר. ככה זה זז מהר, ולכן לומדים עקרונות ולא רק כפתורים.
- כל פרט מוצר שמסומן [לאמת] לא נכנס לשקף לפני שנבדק.
- ההבדל מקורסים מוקלטים: כאן כל אחד יוצא עם צוות שבנה בעצמו, בלייב.
