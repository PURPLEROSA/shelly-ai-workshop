## לבנות מחדש
```bash
npm install          # pptxgenjs, sharp, lucide-static
node prep.js         # מקטין תמונות (מקור: /tmp/site/assets) ומייצר אייקונים
./make.sh            # בונה את grok-bot-workshop.pptx
```
- `lib.js`: רכיבי העיצוב (כרטיסים, תיבות מפגש, ✓, כפתור כהה, מסגרת תמונה מוטה, פרומפט "אתם נותנים / מקבלים")
- `slides-a.js`: פתיחה, 01 יסודות, 02 מי אני, 03 תפקיד ועיצוב, הפסקה
- `slides-b.js`: 04 סושיאל, 05 עוד סוכנים (דיוור, אתרים, בוטים מוכנים, dr eggbot, ראש מטה), 06 סקילים, 07 מקימים בלייב, סגירה
