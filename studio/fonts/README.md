# פונטים לכתוביות

כל הפונטים בתיקייה הזו מופצים ברישיון הפתוח [SIL Open Font License 1.1](https://openfontlicense.org)
ומקורם ב-Google Fonts: Heebo, Rubik, Assistant, Secular One, Karantina, Frank Ruhl Libre, Fredoka, Suez One.

## פונט משלך

כל קובץ `.ttf` או `.otf` שמניחים בתיקייה `custom/` מופיע אוטומטית ברשימת הפונטים של הכתוביות.

קובץ בשם `custom/brand.otf` (או `brand.ttf`) משמש גם כפונט הכותרות של הממשק עצמו.
